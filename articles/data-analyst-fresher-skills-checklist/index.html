What skills does a data analyst fresher need?

A data analyst fresher needs advanced Excel, SQL joins, subqueries and CTEs, one BI tool such as Power BI, Python with Pandas for data cleaning, basic statistics and data storytelling. A portfolio of real projects matters more than a list of tools, because it shows the skills working together.

By Akhil Shibu, fresher data analyst · Published 2026-11-01

1. Advanced Excel

Pivot tables, VLOOKUP and XLOOKUP, slicers and KPI cards still cover most small-team reporting. Build at least one Excel dashboard end to end, such as the bike sales Excel dashboard.

2. SQL for data analysis

Learn joins, subqueries, CTEs, aggregation and window functions such as RANK() OVER. Practise on a real dataset, as in the SQL window functions article.

3. A BI tool such as Power BI

Know how to model data as a star schema, write basic DAX measures and design a dashboard that answers one question. Follow the Power BI dashboard guide.

4. Python for data analysis

Pandas for cleaning (missing values, duplicates, inconsistent labels) is the minimum. NumPy and Matplotlib help with checks and quick charts. Data cleaning in Python is what the Datasentrix project automates.

5. Statistics and data storytelling

Understand averages, distributions and outliers (for example Z-scores), then explain findings in plain language with a recommendation. Hiring managers read the conclusion first.

6. A portfolio that proves it

Three well-explained projects beat ten tool badges. Browse the data analyst portfolio projects on this site to see how each skill appears in a real case study.
