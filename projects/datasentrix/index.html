Datasentrix: Automated Data Cleaning and Reporting Platform

Datasentrix is a Python and Django platform that automates the work analysts repeat before every dashboard. It validates uploaded spreadsheets, drops records with null primary keys, isolates outliers with Z-scores, aggregates cohort retention and generates KPI reports, so cleaning becomes repeatable instead of manual.

CodeRepository to be published on GitHub

What problem does this project solve?

Ad-hoc data preparation in commercial teams leads to errors that cannot be repeated, schema drift between files, and dashboards that disagree with each other because each analyst cleaned the data differently.

How was it built? (method)

  1. Ingest spreadsheets from several sources and check them against an expected schema.
  2. Drop records whose primary key is null and log how many were removed.
  3. Isolate outliers with Z-scores instead of deleting them silently.
  4. Run cohort retention aggregations on the cleaned data.
  5. Generate KPI outputs and report the validation yield (share of records kept).

What is a Z-score outlier check?

A Z-score measures how many standard deviations a value sits from the column average. Values far from the mean are flagged for review, which isolates data-entry errors without distorting trend lines.

Frequently asked questions

What is Datasentrix?+

Datasentrix is an automated data hygiene and reporting platform built with Python, Django and SQL. It validates spreadsheets against a schema, removes records with null primary keys, flags outliers with Z-scores and produces KPI and cohort reports, replacing repeated manual cleaning with rules that can be re-run.

What problem does Datasentrix solve?+

It solves unrepeatable data preparation. When each analyst cleans a spreadsheet by hand, schema drift and silent errors creep in and dashboards stop agreeing. Datasentrix applies the same documented validation rules to every file and reports how many records passed.

What technologies does Datasentrix use?+

Datasentrix is written in Python and uses the Django framework for the web layer, with SQL for storage and aggregation. Data validation, Z-score outlier detection and cohort modelling are implemented as Python pipeline steps. The project is being prepared for publication on GitHub.
